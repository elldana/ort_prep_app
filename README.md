# ORT Prep App — Мобильное приложение для подготовки к ОРТ

Кроссплатформенное мобильное приложение на **Flutter**, разработанное с использованием паттерна управления состоянием **BLoC** и интеграцией с **REST API**

## Функционал
- Загрузка списка предметов ОРТ и тестовых вопросов с сервера (`GET /subjects`)
- Интерактивное прохождение тестов с мгновенной проверкой ответа и прогресс-баром
- Отправка результатов прохождения теста на сервер (`POST /results`)
- Отображение истории попыток с сервера (`GET /results`)

## Стек технологий и архитектура
- **Flutter & Dart** (Material 3)
- **State Management:** `flutter_bloc` + `equatable` (`SubjectsBloc`, `QuizBloc`)
- **Networking:** `http` (REST API интеграция через MockAPI)
- **Архитектура:** разделение на слои `models/`, `services/`, `bloc/` (events, states, bloc) и `screens/`
